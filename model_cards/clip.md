# CLIP (Contrastive Language-Image Pretraining)

**Category:** Multimodal representation learning  

## Constraint profile
- 🎯 Predictive: 🔥🔥🔥 (cross-modal prediction)  
- ✂️ Minimality: ⚪  
- ⏱️ Temporal: ⚪  
- 👁️ Observation: ⚪  
- 🛡️ Invariance: 🔥🔥🔥 (semantic invariance)  
- 🧩 Structure: 🔥🔥 (alignment structure)  

## Intuition
CLIP aligns representations across modalities using contrastive learning.

## CLSM interpretation
Emphasizes invariance and semantic alignment across modalities; weak observation compatibility and minimality constraints.
